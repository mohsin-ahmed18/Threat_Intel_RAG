How this pipeline works

Ingestion — CVE records pulled live from the NVD API, MITRE ATT&CK techniques parsed from official STIX 2.1 bundles, chunked using each source's natural structure (one record per chunk unless oversized).

Embedding — BGE-M3 produces hybrid dense + sparse vectors per chunk, stored in Qdrant with full metadata for filtering.

Retrieval — hybrid search fuses dense (semantic) and sparse (lexical) results via Reciprocal Rank Fusion, so exact identifiers like technique IDs match as reliably as paraphrased questions.

Reranking — BGE-Reranker-v2 cross-encodes the query against each candidate to sharpen relevance ordering before generation.

Generation — GPT-4o answers strictly from retrieved context, citing every claim back to its source record.
